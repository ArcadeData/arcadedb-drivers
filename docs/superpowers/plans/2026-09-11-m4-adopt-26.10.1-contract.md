# M4: Adopt the 26.10.1-SNAPSHOT Contract — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move all four driver packages from the `26.9.1` contract to `26.10.1-SNAPSHOT`, green in CI and e2e, adding no public surface.

**Architecture:** The contract is the single source of truth and generated code is never hand-edited, so almost all of this is running two scripts and committing their output. Exactly one file needs thought: `openapi-typescript` now unions the two media types declared under the `200` of `/query` and `/command`, so `facade/data.ts` receives `QueryResponse | NdJsonQueryEvent` where it used to receive `QueryResponse`. A named narrowing function absorbs that, with a comment recording that the ndjson branch is unreachable *because this client never asks for it* — the fact that changes in drivers#39.

**Tech Stack:** `openapi-typescript` + `openapi-fetch` (TS HTTP), `buf` + `@connectrpc/connect` (TS gRPC), `openapi-python-client` + `httpx` (Python HTTP), `grpc_tools.protoc` (Python gRPC), vitest, pytest, mypy, ruff, eslint.

**Spec:** `docs/superpowers/specs/2026-09-11-contract-26.10.1-migration-design.md` (§4, M4)

**Issue:** ArcadeData/arcadedb-drivers#36. Merging closes #21 and #31.

## Global Constraints

- Generated code is **never** hand-edited: `typescript/packages/driver/src/generated/`, `typescript/packages/driver-grpc/src/gen/`, `python/packages/*/src/*/_generated/`. If output looks wrong, the contract or the generator config is wrong.
- `contracts/` holds **exactly one** OpenAPI JSON and **exactly one** `.proto` at rest. Two of either breaks generation; the two-file state exists only between fetch and adopt, inside Task 1.
- Target version string, used verbatim everywhere: `26.10.1-SNAPSHOT`.
- Target image, used verbatim: `arcadedata/arcadedb:26.10.1-SNAPSHOT`.
- TypeScript: Node >= 20 for unit/typecheck, Node >= 22.22 for e2e (testcontainers@12). ESM-only.
- Python: floor 3.10. Run everything from `python/` through `uv run`.
- **No new public surface in M4.** No use of `application/x-ndjson`, none of the three `/api/v1/vector/*` endpoints, neither `/api/v1/cluster/*` endpoint, none of the 42 new RPCs.
- README compatibility-table rows are historical fact. `adopt-contract-version.sh` deliberately leaves them alone; adding the new row is a human edit, in Task 3.
- Branch: `contract/26.10.1-snapshot`. Never commit to `chore/contract-refresh` — `contract-watch.yml` force-pushes it daily.

- [ ] **Step 3: Add the narrowing function**

In `typescript/packages/driver/src/facade/data.ts`, directly above `toEnvelope`:

```ts
type QueryResponse = components["schemas"]["QueryResponse"];
type NdJsonQueryEvent = components["schemas"]["NdJsonQueryEvent"];

/**
 * Narrows the `200` payload of `/query` and `/command` to the buffered JSON envelope.
 *
 * `openapi-typescript` unions every media type declared under a response code, and
 * ArcadeData/arcadedb#7306 added `application/x-ndjson` beside `application/json` on
 * these two responses - so `unwrap` now yields `QueryResponse | NdJsonQueryEvent`
 * where it used to yield `QueryResponse` alone.
 *
 * This client never sends `Accept: application/x-ndjson`, so the ndjson branch is
 * unreachable, and this function's job is to say so out loud. `{}` satisfies both
 * members (every field of both is optional), so the tie is broken by the encoding
 * that was actually requested rather than by shape: only a payload carrying a key
 * that exists ONLY on the streaming event is treated as one.
 *
 * The throw is not defensive noise. Without it a stray ndjson line would flow
 * through `toEnvelope` and become `{ result: [], limit: -1, returned: 0,
 * truncated: false }` - an answer asserting completeness that nobody gave.
 *
 * When the streaming surface lands (drivers#39) this stops being an assertion and
 * becomes the real discriminator between the two encodings.
 */
function asQueryResponse(data: QueryResponse | NdJsonQueryEvent): QueryResponse {
  if ("record" in data || "stats" in data || "error" in data) {
    throw new ArcadeDBError(200, {
      error: "the server answered with a streamed ndjson event, an encoding this client never requests",
    });
  }
  return data;
}
```

- [ ] **Step 4: Use it at both call sites**

In `executeQuery` (around line 114) and `executeCommand` (around line 136), wrap the value handed to `toEnvelope`:

```ts
  return toEnvelope<T>(asQueryResponse(data));
```

`adopt-contract-version.sh 26.10.1` will rewrite this row's `26.10.1-SNAPSHOT` to `26.10.1`, which
is exactly right for a row describing an unreleased package — and the released `| 0.1.0 | 26.9.1 |`
row above it stays frozen, which is the point of the skip. M9 then drops the `(unreleased)` label
by hand.
